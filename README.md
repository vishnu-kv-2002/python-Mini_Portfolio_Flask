# 🌐 Personal Portfolio – Vishnu K V

A simple personal portfolio website built using **Python, Flask, HTML, CSS, and JavaScript** to showcase my profile, skills, and social media connections.

## 🚀 Technologies Used

- **Python** – Backend programming
- **Flask** – Web framework
- **HTML5** – Webpage structure
- **CSS3** – Styling and design
- **JavaScript** – Basic interactivity

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd My-Portfolio
```

**3. Install Flask**

```bash
pip install flask
```

**4. Run the application**

```bash
python main.py
```

**5. Open in your browser**

```text
http://127.0.0.1:5000/
```
